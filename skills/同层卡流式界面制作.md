# 同层卡流式界面制作

通过 `mountStreamingMessages` 函数，为酒馆聊天楼层的角色消息创建**自定义流式界面**，替换原生的楼层正文显示。

## 核心概念

流式界面本质是**为每个角色消息楼层挂载一个独立的 Vue 组件**。该组件通过 `injectStreamingMessageContext` 获取当前楼层的消息内容和流式状态。

## 快速开始

### 1. 基础模板结构

```
src/你的流式界面/
├── App.vue              # 主入口组件
├── main.ts              # 挂载点
└── 组件目录/
    └── 你的组件.vue
```

### 2. 入口文件 (main.ts)

```typescript
import { createApp } from 'vue';
import { mountStreamingMessages } from '@util/streaming';
import App from './App.vue';

mountStreamingMessages(() => createApp(App), {
  host: 'iframe',           // 推荐: 样式隔离，可使用 tailwindcss
  // host: 'div',            // 备选: 继承酒馆样式，不能用 tailwindcss
  filter: (message_id, message) => {
    // 可选: 过滤需要挂载的楼层
    return message.includes('<特定标识>');
  },
  prefix: 'my-streaming',   // 可选: 组件唯一标识
});
```

### 3. 主组件模板 (App.vue)

```vue
<template>
  <!-- 你的界面内容 -->
  <div>{{ context.message }}</div>
</template>

<script setup lang="ts">
import { injectStreamingMessageContext } from '@util/streaming';

const context = injectStreamingMessageContext();

// context 包含:
// - message_id: number     // 楼层号
// - message: string        // 消息内容
// - during_streaming: boolean  // 是否正在流式传输
// - prefix: string         // 组件前缀
// - host_id: string        // 宿主元素 ID
</script>
```

## 核心 API

### `mountStreamingMessages(creator, options)`

**参数说明：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `creator` | `() => App` | 必填 | 返回 Vue 应用的工厂函数 |
| `options.host` | `'iframe' \| 'div'` | `'iframe'` | 宿主类型 |
| `options.filter` | `(message_id, message) => boolean` | 无 | 楼层过滤器 |
| `options.prefix` | `string` | 随机 UUID | 组件唯一标识 |

**返回值：**

```typescript
{ unmount: () => void }
```

### `injectStreamingMessageContext()`

**返回的响应式上下文：**

```typescript
type StreamingMessageContext = {
  prefix: string;           // 组件前缀
  host_id: string;          // 宿主元素 ID
  message_id: number;       // 楼层号
  message: string;          // 消息内容
  during_streaming: boolean; // 是否正在流式传输
};
```

## 宿主模式对比

### iframe 模式 (推荐)

```typescript
host: 'iframe'
```

**优点：**
- ✅ 样式完全隔离，不会影响酒馆其他部分
- ✅ 可以使用 tailwindcss
- ✅ 组件内样式不会泄漏到外部

**缺点：**
- ❌ 需要处理 iframe 通信

### div 模式

```typescript
host: 'div'
```

**优点：**
- ✅ 继承酒馆原生样式
- ✅ 与酒馆 UI 更融合

**缺点：**
- ❌ 不能使用 tailwindcss
- ❌ 样式可能与酒馆冲突
- ❌ 不能使用 `mes_text` 类名（会破坏编辑功能）

## 消息格式化

使用 `formatAsDisplayedMessage` 处理消息内容：

```typescript
import { formatAsDisplayedMessage } from '@types/function';

// 基本用法
const html = formatAsDisplayedMessage("{{char}} 说: {{lastMessage}}");

// 带楼层指定
const html = formatAsDisplayedMessage(text, { message_id: 5 });

// 适配 div 宿主（将 mes_text 替换为 mes_streaming）
const formatted = formatAsDisplayedMessage(message, { message_id: context.message_id })
  .replaceAll('mes_text', 'mes_streaming');
```

## 完整示例

### 示例结构

```
示例/流式楼层界面示例/
├── App.vue           # 主组件（含搜索和高亮功能）
├── 分段.vue          # 按行分段显示组件
├── 搜索框.vue        # 关键词高亮搜索框
└── 高亮.vue          # 文本高亮组件
```

### App.vue 完整示例

```vue
<template>
  <SearchBar v-model="query" />

  <Segment v-if="before_html" :query :html="before_html" />

  <template v-if="before_index !== -1">
    <Segment v-if="middle_html" :query :html="middle_html" />
    <Highlighter v-else :query>
      <RoleplayOptions :message="context.message" />
    </Highlighter>
  </template>

  <Segment v-if="after_html" :query :html="after_html" />
</template>

<script setup lang="ts">
import { injectStreamingMessageContext, formatAsDisplayedMessage } from '@util/streaming';
import RoleplayOptions from './选择框.vue';
import Segment from './分段.vue';
import SearchBar from './搜索框.vue';
import Highlighter from './高亮.vue';

const context = injectStreamingMessageContext();
const query = ref('');

// 解析角色选项标记
const before_index = computed(() => {
  return context.message.lastIndexOf('<roleplay_options>');
});

// 前置内容（角色选项之前）
const before_html = computed(() => {
  return formatAsDisplayedMessage(
    context.message.slice(0, before_index.value === -1 ? undefined : before_index.value).trim(),
    { message_id: context.message_id },
  );
});

// 后置内容（角色选项之后）
const after_index = computed(() => {
  return context.message.lastIndexOf('</roleplay_options>');
});
const after_html = computed(() => {
  if (after_index.value === -1) return null;
  return formatAsDisplayedMessage(
    context.message.slice(after_index.value + 19).trim(),
    { message_id: context.message_id },
  );
});

// 中间内容（角色选项未闭合时）
const middle_html = computed(() => {
  if (before_index.value !== -1 && after_index.value === -1) {
    return formatAsDisplayedMessage(
      context.message.slice(before_index.value).trim(),
      { message_id: context.message_id },
    );
  }
  return null;
});

// 监听流式传输完成
watch(
  () => context.during_streaming,
  (during) => {
    if (!during) {
      toastr.success(`第 ${context.message_id} 楼流式传输已完成`);
    }
  },
);

onMounted(() => {
  toastr.success(`成功挂载第 ${context.message_id} 条消息的流式楼层界面`);
});
</script>
```

### 分段.vue (可点击展开的折叠内容)

```vue
<template>
  <div class="StreamingMessage__segments">
    <div
      v-for="segment in segments"
      :key="segment.key"
      class="StreamingMessage__segment"
      :class="{ 'is-hidden': !isRevealed(segment.key) }"
      @click.stop="reveal(segment.key)"
    >
      <div class="StreamingMessage__segmentContent" :class="{ 'is-blurred': !isRevealed(segment.key) }">
        <Highlighter :query :html="segment.html" />
      </div>
      <div v-if="!isRevealed(segment.key)" class="StreamingMessage__segmentHint">点击显示</div>
    </div>
  </div>
</template>

<script setup lang="ts">
import Highlighter from './高亮.vue';

const props = defineProps<{ query: string; html: string }>();

const revealed = ref(new Set<number>());
const reveal = (key: number) => revealed.value.add(key);
const isRevealed = (key: number) => revealed.value.has(key);

type HtmlSegment = { key: number; html: string };
const splitHtmlByNewline = (html: string): HtmlSegment[] => {
  const segments: HtmlSegment[] = [];
  const lines = html.split(/\r?\n/);
  lines.forEach((line, index) => {
    if (line?.trim()) segments.push({ key: index, html: line.trim() });
  });
  return segments;
};
const segments = computed(() => splitHtmlByNewline(props.html));
</script>

<style scoped lang="scss">
```

## 导入到酒馆

### 1. 创建脚本 JSON

在 `初始模板/流式楼层界面/导入到酒馆中/` 目录下创建脚本文件：

```json
{
  "id": "你的唯一id",
  "name": "流式楼层界面脚本名称",
  "content": "import 'http://localhost:5500/dist/你的打包路径/index.js'",
  "info": "描述信息",
  "buttons": []
}
```

### 2. 打包配置

确保 Vite 配置支持外部访问（开发时使用 localhost:5500）：

```typescript
// vite.config.ts
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';

export default defineConfig({
  plugins: [vue()],
  server: {
    port: 5500,
    origin: 'http://localhost:5500',
  },
  build: {
    target: 'esnext',
  },
});
```

## 注意事项

1. **样式隔离**：iframe 模式下样式完全隔离，但需要确保所有样式都在组件内定义
2. **消息过滤**：使用 `filter` 选项可以精确控制哪些楼层需要自定义界面
3. **流式监听**：通过 `watch(context.during_streaming)` 监听流式传输状态
4. **DOM 操作**：避免直接操作酒馆原生 DOM，使用 `formatAsDisplayedMessage` 格式化内容
5. **类名冲突**：div 模式下不要使用 `mes_text` 类名，会破坏酒楼的编辑功能
6. **卸载清理**：`mountStreamingMessages` 返回的 `unmount()` 函数会在页面刷新或聊天切换时自动调用
