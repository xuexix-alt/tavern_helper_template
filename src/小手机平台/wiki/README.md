# 小手机平台 Code Wiki

「小手机平台」是一套运行于 **SillyTavern（酒馆）+ 酒馆助手（Tavern Helper）** 环境中的「微信模拟手机」平台源码。它由多个互相独立的酒馆助手脚本组成，通过一个挂在 `window.top` 上的微内核运行时（`TavernPhone`）汇聚成完整系统，为角色卡提供：手机外壳 UI、微信聊天、人物档案 AI 分析、末日公共广播、智能任务等玩法。

> 适用源码范围：`src/小手机平台/`（角色专用适配器 `src/寒冬末日/脚本/小手机-90寒冬适配器/` 作为外部集成方，仅在[架构总览](01-架构总览.md)与[外部集成](08-依赖关系与外部集成.md)中说明）。

## 目录速览

```
src/小手机平台/
├── core/           # 微内核运行时（模块/服务/事件总线/健康检查）
├── platform/       # 酒馆宿主适配层（生成 API/楼层读取/设置/宿主事件）
├── data/           # 数据层（IndexedDB PhoneDB/世界书同步/摘要）
├── ai/             # AI 能力层（Provider/提示词组装/破限/解析/重试）
├── scheduler/      # 受控任务调度器
├── shell/          # 手机外壳（Shadow DOM 模态 UI + 样式）
├── apps/           # 内置 APP 定义与 UI 渲染
├── profiles/       # 人物档案体系（AI 增量分析路线）
├── intelligence/   # 智能情报体系（简化并行路线）
├── assets/         # 静态资源（微信图标）
├── 脚本/            # 酒馆助手脚本入口（00~90，每目录一个入口）
└── __tests__/      # 自包含 Node 测试脚本
```
