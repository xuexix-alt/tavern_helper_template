                步骤 7 —— 离场 / 永久逃离角色本字段不更新。
                示例：

                    · `-6, 协作负向·背弃盟约`

                【离场角色】由脚本自动写回，AI 不输出 patch。

        变量名：伊甸一次性指令.${编号}.数量
            变量地址：stat_data.伊甸一次性指令.${编号}.数量
            格式：number
            **计算规则**：
                新增获得：`delta` +1；若 `${编号}` 尚不存在，先 `insert /伊甸一次性指令/${编号}` 写入完整对象（含 `生效实例: []`），再对本字段累加。
                发动使用：`delta` -1，并**同步新增生效实例**（见下条）。

        变量名：伊甸一次性指令.${编号}.生效实例
            变量地址：stat_data.伊甸一次性指令.${编号}.生效实例
            格式：`{ 对象范围: string; 剩余时效: string; }[]`
            字段约束：
                - `对象范围`：必须与指令【范围】定义一致，写具体承载对象（房间路径如"核心区/客厅"、"楼层20/2002"，或角色姓名如"雪乃"，或户外地点如"户外/停车场"）。禁止写"全体/未定/随机"等模糊值。
                - `剩余时效`：仅允许三类写法：
                    1) 计时类："约${N}小时" / "约${N}分钟"（N 为正整数或 0.5 的倍数）
                    2) 单次行动类："尚在起作用"
                    3) 延迟起效类："${N}小时后起作用"（仅 sk002 等延迟生效指令用）
                - 禁止对象化数组项（不得写成 `{"实例1": {...}}`），也不得追加额外字段。

            **计算规则**（按"发动 → 推进 → 结束"三态）：

              【发动态】本轮首次发出，同步完成：
                1. `delta /伊甸一次性指令/${编号}/数量` -1
                2. `replace /伊甸一次性指令/${编号}/生效实例` 整体写入（在原数组基础上追加新项）
              初始【剩余时效】按标称【时效】换算：
                - 时长（6小时/12小时/24小时/5分钟）→ "约${N}小时" 或 "约${N}分钟"。
                - "单次行动"：本轮已完成 → 不写入；本轮未完成 → "尚在起作用"。
                - "6小时后起作用"（sk002）→ "6小时后起作用"。
              示例（sk001 作用于核心区/客厅，6小时）：
                ```json
                [
                  { "op": "delta", "path": "/伊甸一次性指令/sk001/数量", "value": -1 },
                  {
                    "op": "replace",
                    "path": "/伊甸一次性指令/sk001/生效实例",
                    "value": [ { "对象范围": "核心区/客厅", "剩余时效": "约6小时" } ]
                  }
                ]
                ```

              【推进态】已在数组中，本轮未结束 → 只改【剩余时效】：
                - 以本轮【世界.时间】相对上一轮的 Δt（分钟）作减量。
                - 新剩余 = 上一轮剩余 - Δt；归一：
                    · ≥60 分钟 → 四舍五入到 0.5 小时，写 "约${N}小时"。
                    · <60 且 >0 → 四舍五入到 5 分钟，写 "约${N}分钟"。
                    · ≤0 → 进入【结束态】，不写入本字段。
                - "尚在起作用"：本轮未完成 → 不动；本轮完成 → 进入【结束态】。
                - "${N}小时后起作用"（sk002）：
                    · 等待期未到 → 按归一规则写 "${剩余}小时后起作用"。
                    · 等待期归零 → **同一轮内**再 `replace` 一次切换为生效期写法（sk002 → "约6小时"），并在正文体现"开始生效"。
                - 每个实例独立；未变项不产出 patch。
              推进示例（核心区/客厅 sk001，Δt=120 分钟）：
                ```json
                { "op": "replace", "path": "/伊甸一次性指令/sk001/生效实例/0/剩余时效", "value": "约4小时" }
                ```

              【结束态】满足任一 → `remove` 删除该实例：
                - 计时类新剩余 ≤ 0；
                - 单次行动本轮已结算完成（成功/失败/被打断皆算）；
                - 对象范围失效（目标角色死亡/离开作用区域/区域不再存在）或剧情主动撤销。
              删除写法：
                ```json
                { "op": "remove", "path": "/伊甸一次性指令/${编号}/生效实例/${序号}" }
                ```
              多项删除按**序号从大到小**依次 remove；空数组保留 `[]`；不回补数量。

              易错点自查：
                - 不要同时整体 `replace 生效实例` + 局部 `replace .../剩余时效`；发动态用前者，推进态用后者。
                - 到期要 `remove`，不要写 "已结束/0小时"。
                - 同编号多实例各自独立，【对象范围】必须不同。
                - 发动态追加新项时，`replace` 的 value 必须是"原数组 + 新项"的完整数组。
