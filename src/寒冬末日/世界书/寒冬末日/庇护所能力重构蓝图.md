# 庇护所能力重构蓝图

> 用于重构 `庇护所升级能力.txt` 的系统蓝图。目标不是先写满文案，而是先把能力体系的成长结构、系统分工和不同流派的镜头重点定死。

---

## 1. 重构目标

- 保留同一份庇护所能力总表，不按世界观档位拆多份能力库。
- 把能力系统从“设施/技能拼盘”改成“庇护所六大基础系统”的线性成长树。
- 让玩家从第 1 级就感受到：
  - 有优势，但不够稳
  - 能守住一小块地，但必须继续扩张
  - 每次升级都不是多一个花哨功能，而是庇护所整体更能活、更能守、更能养、更能管、更能往外推
- 世界观档位和主流派不改变能力库本身，只改变：
  - 起手权重
  - 提示词强调
  - 初始短板
  - 前几轮任务镜头

---

## 2. 六大系统定义

### `energy`

- 定义：能源、供暖、配电、维持时长、系统开机能力。
- 核心问题：庇护所能不能转起来、能转多久、能带动多少模块。
- 玩家感受：从“勉强开机”到“多区域稳定运转”。

### `security`

- 定义：入口防线、观察预警、局部压制、楼层安全控制。
- 核心问题：能不能守住，守住多大范围，能不能把威胁挡在外面。
- 玩家感受：从“2001 不容易被破门”到“楼层内有真正控制力”。

### `sustain`

- 定义：食物、净水、医疗、卫生、基本生存保障。
- 核心问题：能不能多活几个人、是否能承受更多人口与伤病压力。
- 玩家感受：从“自己活”到“养团队、养伤员、养共同体”。

### `life`

- 定义：热水、洗浴、影院、舞台、温室庭院、折景旅游、室外桃源式的末日独享生活设施。
- 核心问题：庇护所能否提供外界绝不可能拥有的生活质量，并因此吸引主角和角色们主动留下。
- 玩家感受：从“终于能洗个热水澡”到“这里像旧世界的乐园碎片”再到“穹顶下的室外桃源”。

### `social`

- 定义：监听、全息直播、场景回放、情绪画像、谈判展示、时空片段回溯、IMP增益与情感操控优势。
- 核心问题：如何对对手、交易对象和社区内部持续获得情报优势与情感优势，并把它们转成IMP增长、谈判收益和主导权。
- 玩家感受：从“我先知道”到“我更懂你”再到“所有接触都会被我的情报和情感优势放大”。

### `expansion`

- 定义：控制半径、外扩节点、收编、征服、接管、跨层推进。
- 核心问题：优势能推进到哪里，谁被纳入庇护范围，是否形成外部势力影响力。
- 玩家感受：从“2001 室”到“20 层”再到“整栋楼/片区秩序中心”。

### 约束下沉原则

- `限制` 不再作为独立能力大类。
- 原有“限制类”内容统一下沉为各能力的：
  - `boundary`
  - `upkeep`
  - `cap`
  - `population_dependency`
- 目的：让每条能力天然带着代价、前提与边际，而不是出现一整类“看起来像福利项的限制能力”。

## 3. 流派镜头与起手权重

> 流派不改能力树，只改“开局从哪几条系统先爽、先痛、先卷”。

| 流派 | 起手强项 | 起手短板 | 前期任务镜头 | opening 关键词 |
| - | - | - | - | - |
| `守` | `security` + `expansion` | `life` + `social` | 修补防线、观察威胁、压制试探、决定是否外扩 | 守得住 / 还不稳 / 危险近在门外 |
| `养` | `energy` + `sustain` | `security` + `expansion` | 配给、供暖、救人、轮值、医疗优先级 | 多活一个人就是系统资本 |
| `管` | `social` + `expansion` | 纯压制与纯产出不突出 | 定规则、分配、接触、谈判、纳管、交易 | 秩序本身就是资源 |

## 5. 后续改写顺序

### 第一阶段：重构分类，不先重写全部文案

- 把现有能力先重标到 6 大系统：
  - `energy`
  - `security`
  - `sustain`
  - `life`
  - `social`
  - `expansion`
- 把原 `limit.*` 从主能力大类中移出，改写为各能力内部的：
  - `boundary`
  - `upkeep`
  - `cap`
  - `population_dependency`

### 第二阶段：先重写 1-5 级

- 因为 opening 和前期体验最重要。
- 重点先做出：
  - `守` 的起手爽点
  - `养` 的起手压力
  - `管` 的起手秩序感
- 目标：让三种路线在同一套能力体系里自然分化。

### 第三阶段：高阶能力收束为“区域控制权”

- `6-10` 级不要再堆小设备。
- 要体现的是：
  - 你的庇护所不只是更强
  - 而是从“房间 -> 楼层 -> 跨层 -> 区域秩序中心”

## 6. 编写时的硬规则

- 每条能力都要回答 3 个问题：
  - 它让玩家比别人强在哪？
  - 它为什么仍然不够？
  - 它推动玩家下一步去哪里进取？
- 避免写成单纯设备炫技；优先写成“系统级能力合同”。
- 前 5 级的任何能力都不能破坏以下体验：
  - 2001 是安全的，但不是全知全能的
  - 玩家有明显优势，但外部世界仍然危险且有吸引力
  - 多收一个人、多管一个房间、多推出一段走廊，都是真实决策
