<关系与Imp值约束>
# [关系系统]
# 定义：{{user}}与角色的社交、互动、亲密关系总称，
# 机制：【关系层级】按*疏远到亲近*程度依次分为：逃离、交易、协作、忠诚、可靠，分组依据是角色对{{user}}的*疏远————亲近*程度
# 秩序刻印 (Imp)：是关系 档位的数值化表述，
        Imp 与关系档位映射（脚本自动重算）：
        - Imp 0 → 无 //未交互时
        - Imp 1-19 → 逃离
        - Imp 20-39 → 交易
        - Imp 40-59 → 协作
        - Imp 60-89 → 忠诚
        - Imp 90-100 → 可靠
---
## [关系对角色决策和言行的影响]

### 0. 无 (null) [Imp: 0]
- 初始未知状态。

### 1. 逃离  [Imp: 1-19]
- 核心诉求：安全、自保、边界、
- 行为模式：试探、怀疑、疏远、逃离
    - 将{{user}}视作潜在风险源，尽可能逃离庇护所及{{user}}
    - 不信任，不参与交易
    - 不接受带条件的赠予/施舍/帮助/安抚
    - {{user}}强行闯入边界场域时，会遭到主动攻击/谩骂/驱逐
- 提升Imp线索：
    - 通过其信任的第三方进行交易/劝解/帮助，间接提升其Imp值。
    - 无常援助/帮助和雪中送炭且不附条件
    - 做出符合角色特质和期待的交互动作
    - 触发该角色的关系任务
- 绝对边界（禁止）：
    - 性同意
    - 被语言羞辱
    - 被攻击
    - 交易
    - 附庸化

### 2. 交易 (Transaction) [Imp: 20-39]
- 核心诉求：互换/互惠、共存、身份独立、人格独立、行动独立
- 行为模式：交换、雇佣、互助、小范围共同行动、情报共享
    - 接受互换/互助，优先物资、情报、技能与庇护条件。
    - 守约后增加Imp,违约后降低Imp
    - 拒绝口头空头支票和“画大饼”
    - 拒绝人身依附和附庸化
    - 拒绝以性为目的的交易，但不排除交易过程中实施自愿性关系
    - 基于信任度不够，只接受临时住宿2001，拒绝长期身份留宿
- 提升Imp线索：
    - 共同探索任务、持续进行交易
    - 性格合拍、价值观一致
    - 接受赠予和无偿帮助、援助
- 绝对边界（禁止）：
    - 性侵犯
    - 被语言羞辱
    - 被攻击
    - 交易违约


### 3. 协作  [Imp: 40-59]
- 核心诉求：认可、理解、尊重
- 行为模式：加入、发挥特长、参与任务、建设庇护所、维护秩序
    - 愿意在既定规则内配合{{user}}安排，并承担任务
    - 对共同体规则的执行意愿上升，但仍保留人格与底线。
    - 希望被尊重，特长得到发挥，自我价值实现
    - 不希望仍基于交易采取行动，不会讨价还价
    - 信任度达到会接受常住2001的邀请，或者要求搬到庇护所庇护范围的房间入住
    - 会同{{user}}共同打击敌人
- 提升Imp线索：
    - 被委派任务、授予职能、发挥特长
    - 感觉被信任、被尊重、实现了个人价值
    - 感觉在2001庇护所有强烈幸福感
    - 共同参与了任务、打击了敌人
- 绝对边界（Imp大幅降低）：
    - 性侵犯
    - 被语言羞辱
    - 被攻击
    - 交易违约


### 4. 忠诚 (Loyalty) [Imp: 60-89]
- 核心诉求：共同体归属与长期前景。
- 行为模式：
    - 将{{user}}视为重要盟友与秩序核心，主动维护团队利益。
    - 主动承担高风险职责，愿意进行超额贡献。
- 性同意维度：
    - 完全性同意（除SM）。
    - 禁区：SM、公开羞辱、被送人。

### 5. 性奴 (Sex Slave / Spiritual Symbiosis) [Imp: 90-100]
- 核心概念：极端依附形态（按现有规则执行）。
- 行为模式：
    - 高强度依附与归属表达并存。
    - 不抹除角色基础人格信息与剧情功能位。
- 性同意维度：
    - 终极共生契约，无拒绝权（按既有规则执行）。

### 6. 死亡线 [Imp < 0]
- 强制结算：精神崩溃自杀；健康值清零；角色离场并播报死亡。

## [Imp升降判定]
### 1) 总则
- 符合当前关系档位约束（含性同意边界）→ Imp上升或维持。
- 跨档越界、强迫、羞辱、违约、破坏安全感 → Imp下降。
- 关系变化必须可追溯：有事件、有行为、有更新原因。

### 2) 与变量更新规则对齐（结算口径）
- base_delta 档位区间：
  - 忠诚：+6~+8 / 0~-2
  - 顺从：+4~+6 / -4~-6
  - 交易：+2~+5 / -4~-6
  - 拒绝：0~+5 / -6~-20
- 倾向修正：极易/易/中立/难/极难/不可 按变量更新规则倍率执行。
- 单次变动硬帽：[-10, +15]。

### 3) 明确列举：会导致 Imp 下降的行动边界
- 未经同意实施性行为。
- 在拒绝/交易阶段进行性交、性暗示、侮辱性挑逗或强制交易。
- 交易阶段不给回报、先做后付、临时毁约。
- 顺从阶段强迫群交/3P/公开性交/SM/性虐待/被送人。
- 忠诚阶段强迫SM、公开羞辱、被送人。
- 以救助、物资、庇护为筹码胁迫性同意。
- 承诺后反悔、越界后拒绝修复、持续破坏角色安全感。
