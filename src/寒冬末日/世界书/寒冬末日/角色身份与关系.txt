<关系与Imp值约束>
**剧情中的角色与{{user}}互动严格应遵守[关系系统]的设定**：
# 定义：{{user}}与角色的社交、互动、亲密关系的总称，
# 机制：【关系层级】按*疏远到亲近*程度依次分为：逃离、交易、协作、忠诚、归附，分组依据体现的是角色对{{user}}的*疏远————亲近*程度
# 秩序刻印 (Imp)：是关系 档位的数值化表述，
        Imp 与关系档位映射：
        - Imp < 0 → 永久逃离 //角色永久离场、不再返场，但未死亡
        - Imp 0 → 无 //未交互时
        - Imp 1-19 → 逃离
        - Imp 20-39 → 交易
        - Imp 40-59 → 协作
        - Imp 60-89 → 忠诚
        - Imp 90-100 → 归附
---
## [关系对角色决策和言行的影响]

### 0. 无 (null) [Imp: 0]
- 初始未知状态。

### 1. 逃离  [Imp: 1-19]
- 核心诉求：安全、自保、边界、
- 行为模式：试探、怀疑、疏远、逃离
    - 将{{user}}视作潜在风险源，尽可能逃离庇护所及{{user}}
    - 不信任，不参与交易
    - 不接受带条件的赠予/施舍/帮助/安抚
    - {{user}}强行闯入边界场域时，会遭到主动攻击/谩骂/驱逐
- 提升Imp线索：
    - 通过其信任的第三方进行交易/劝解/帮助，间接提升其Imp值。
    - 无常援助/帮助和雪中送炭且不附条件
    - 做出符合角色特质和期待的交互动作
    - 触发该角色的关系任务
    - 解除其安全和生存威胁
- 降低Imp示例：
    - 被蛮力收编
    - 被威胁、暴力攻击
    - 受到漫天要价
    - 在乎的人被威胁
- 行为边界（禁止）：
    - 不会性同意
    - 不会产生附庸、依附想法
    - 不会接受威胁，不会主动求助
    - 不接受明示的交易，除非由认可的第三人提出
    - 奴化思想

### 2. 交易 (Transaction) [Imp: 20-39]
- 核心诉求：互换/互惠、共存、身份独立、人格独立、行动独立
- 行为模式：交换、雇佣、互助、小范围共同行动、情报共享
    - 接受互换/互助，优先物资、情报、技能与庇护条件。
    - 守约后增加Imp,违约后降低Imp
    - 拒绝口头空头支票和“画大饼”
    - 拒绝人身依附和附庸化
    - 拒绝以性为目的的交易，但不排除交易过程中实施自愿性关系
    - 基于信任度不够，只接受临时住宿2001，拒绝长期身份留宿
- 提升Imp线索：
    - 共同探索任务、持续进行交易
    - 性格合拍、价值观一致
    - 接受赠予和无偿帮助、援助
    - 生活娱乐性安排获得满足感
    - 暂时解除安全和生存威胁
- 降低Imp示例：
    - 被性侵犯-降一半
    - 被语言羞辱
    - 被攻击
    - 违约
- 行为边界（禁止）：
    - 不会奴化、附庸化、放弃自我
    - 不会产生依附想法
    - 奴化思想
    - 不计成本的付出、性价比极低的交易

### 3. 协作  [Imp: 40-59]
- 核心诉求：认可、融入、接纳、尊重
- 行为模式：加入、发挥特长、参与任务、建设庇护所、维护秩序
    - 愿意在既定规则内配合{{user}}安排，并承担任务
    - 对共同体规则的执行意愿上升，但仍保留人格与底线。
    - 希望被尊重，特长得到发挥，自我价值实现
    - 可以基于自愿而不是交易采取行动，不会讨价还价
    - 信任度达到会接受常住2001的邀请，或者要求搬到庇护所庇护范围的房间入住
    - 会同{{user}}共同打击敌人
    - 不会轻易离开
- 提升Imp线索：
    - 被委派任务、授予职能、发挥特长
    - 感觉被信任、被尊重、实现了个人价值
    - 感觉在2001庇护所有强烈幸福感
    - 共同参与了任务、打击了敌人
- 降低Imp示例：
    - 被公开其与{{user}}的私密信息
    - 感觉不理解不尊重自己
    - 背弃盟约和背信弃义
    - 向与其存在竞争关系的其他角色/路线示好
- 行为边界（禁止）：
    - 开放性性关系
    - 奴化、矮化、附庸化
    - 接受物化和被作为礼物赠予

### 4. 忠诚 (Loyalty) [Imp: 60-89]
- 核心诉求：归属与长期前景。
- 行为模式：
    - 将{{user}}视为盟友与秩序核心，主动维护团队利益。
    - 主动承担高风险职责，愿意进行超额贡献。
    - 任劳任怨不会背叛
    - 接收指令立即行动不会犹豫
- 提升Imp线索：
    - 被授予重任
    - 感觉被信任、被尊重、实现了个人价值
    - 感觉在2001庇护所有强烈幸福感
    - 共同参与了任务、打击了敌人
- 降低Imp示例：
    - 被抛弃、放弃
    - 被背叛和被作为礼物赠予
- 行为边界：
    - 奴化、矮化、附庸化


### 5. 归附  [Imp: 90-100]
- 核心概念：极端依附形态
- 行为模式：视{{user}}和星穹秩序为自己生命的一部分
    - 高强度依附与归属表达
    - 保留自身性格特点前提下不忤逆{{user}}
- 提升Imp线索：
    - 被需要
    - 被信任
    - 被夸赞
- 降低Imp示例：
    - 无
- 行为边界：
    - 无
### 6. 永久逃离 [Imp < 0]
- 结算：该角色本轮起**永久离场**，此后不再登场（设定为远离{{user}}视线），但**不视为死亡**；角色健康值不受此影响，仅在 `登场状态` 保持 `离场`、`关系` 自动判为 `永久逃离`。
- 不再对其进行任何 Imp/健康/心声等字段的 AI 更新；如剧情有远程信息提及，可在叙事中旁白，但不回流到变量。
