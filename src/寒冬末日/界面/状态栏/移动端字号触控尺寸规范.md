# 寒冬末日状态栏 - 移动端字号/触控尺寸规范（v1）

## 1. 基础原则

- 目标设备：`320px ~ 430px` 宽的手机浏览器（优先单手操作场景）。
- 可点击控件最小高度：常规 `>= 40px`，关键操作 `>= 44px`。
- 小字号下限：正文不低于 `0.84em`，标签/辅助信息不低于 `0.74em`。
- 信息密度策略：优先增加行高和垂直间距，不通过极小字号压缩内容。

## 2. 尺寸规范表

| 元素类型 | 推荐字号 | 推荐行高 | 最小高度/宽度 | 备注 |
| --- | --- | --- | --- | --- |
| 页面主标题（section-title） | `1.0em ~ 1.12em` | `1.25` | `-` | 用于页面级分区 |
| 面板标题（pane tab） | `0.86em ~ 0.92em` | `1.2` | `>= 40px` | 包含图标和短标题 |
| 主内容文本 | `0.86em ~ 0.94em` | `1.3 ~ 1.4` | `-` | 如剧情摘要、说明文本 |
| 卡片标签（label/chip） | `0.74em ~ 0.8em` | `1.2 ~ 1.3` | `>= 24px`（胶囊标签） | 避免低于 `0.72em` |
| 次级注释文本 | `0.74em ~ 0.82em` | `1.3` | `-` | 如提示、状态说明 |
| 普通按钮（次要） | `0.8em ~ 0.88em` | `1.2` | `>= 40px` | 清除、关闭、切换等 |
| 关键按钮（主操作） | `0.84em ~ 0.92em` | `1.2` | `>= 44px` | 发送、确认、提交 |
| 纯图标按钮 | `0.82em ~ 0.9em` | `1` | `>= 40x40` | 关闭、折叠图标等 |
| 输入框/下拉框 | `0.86em ~ 0.94em` | `1.2` | `>= 40px` | 统一输入触控感 |
| 选项 token / mini button | `0.8em ~ 0.84em` | `1.2` | `>= 34px` | 密集区可降到 `34px` |

## 3. 间距规范（推荐）

| 间距类型 | 推荐值 |
| --- | --- |
| pane 内边距 | `8px ~ 10px` |
| 卡片内边距 | `8px ~ 10px` |
| 卡片间距 | `7px ~ 10px` |
| 标题与内容间距 | `6px ~ 10px` |
| 小屏（<=420px）额外压缩 | 每项最多减少 `1px ~ 2px` |

## 4. 响应式断点建议

- `<= 520px`：网格布局可降为单列，保持字号不大幅下降。
- `<= 420px`：优先压缩间距和装饰，再压缩字号（每次不超过 `0.04em`）。
- `<= 360px`：保留关键触控尺寸，允许隐藏次要标签文本。

## 5. 性能和视觉一致性补充

- 移动端浮层特效：`backdrop-filter` 建议在 `<=480px` 关闭或降级。
- 长列表与弹层：避免“双滚动容器”，优先保留单一主滚动区域。
- 同页面内同类型控件（按钮、select、chip）需统一尺寸区间，避免“看起来一样、点起来不一样”。

## 6. 推荐 CSS 变量（可逐步落地）

```css
:root {
  --mobile-text-main: 0.9em;
  --mobile-text-secondary: 0.8em;
  --mobile-text-label: 0.76em;
  --mobile-touch-min: 40px;
  --mobile-touch-key: 44px;
  --mobile-pane-padding: 10px;
  --mobile-card-padding: 9px;
}
```

> 说明：本规范用于约束后续组件开发，允许在个别高密度场景微调，但不应突破最小触控/最小字号底线。
