3月21日0点25分，当前测得在多张图片已经有提示词，插件每生产一张图片会“刷新”一次正文，导致已经生产的图片短暂“不可见”（露出提示词内容），等刚生好的图一起加载回来，直到下一张生好又一起“消失”一点（露出提示词）。这个和原版插件实现有出入，原版新图加载是不影响其他图的，是无感的。
正文核验指令：
(() => {
  const pickDoc = () => {
    try {
      if (window.top?.document?.querySelectorAll('.mes .mes_text').length > 0) {
        return { scope: 'top', doc: window.top.document };
      }
    } catch {}
    return { scope: 'self', doc: document };
  };

  const { scope, doc } = pickDoc();

  return {
    scope,
    allMesTextCount: doc.querySelectorAll('.mes .mes_text').length,
    targets: [2, 4, 6,8,10].map(id => {
      const el = doc.querySelector(`div.mes[mesid="${id}"] .mes_text`);
      const rect = el?.getBoundingClientRect?.();
      const style = el ? getComputedStyle(el) : null;
      return {
        mesid: id,
        exists: !!el,
        textLen: el?.textContent?.length ?? 0,
        preview: (el?.textContent ?? '').slice(0, 120),
        rect: rect
          ? {
              x: rect.x,
              y: rect.y,
              width: rect.width,
              height: rect.height,
            }
          : null,
        style: style
          ? {
              display: style.display,
              visibility: style.visibility,
              opacity: style.opacity,
            }
          : null,
      };
    }),
  };
})();
第一步：确认注入节点存在
javascript(() => {
  const doc = window.top?.document ?? document;
  const nodes = Array.from(doc.querySelectorAll('.mes[data-ui-injected-mes]'));
  return nodes.map(el => ({
    mesid: el.getAttribute('mesid'),
    textLen: el.querySelector('.mes_text')?.textContent?.trim().length ?? 0,
    preview: el.querySelector('.mes_text')?.textContent?.trim().slice(0, 80),
  }));
})();
预期：能看到你目标楼层的 mesid 和正文预览，textLen > 100。

第二步：模拟插件的查找逻辑
把 mesid 换成你实际的楼层号（比如 2）：
javascript(() => {
  const doc = window.top?.document ?? document;
  const mesid = 2; // 换成实际楼层号
  const el = doc.querySelector(`div.mes[mesid="${mesid}"] .mes_text`);
  return {
    found: !!el,
    textLen: el?.textContent?.trim().length ?? 0,
    preview: el?.textContent?.trim().slice(0, 120),
  };
})();
预期：found: true，textLen > 100，preview 是真实正文开头。
两步都通过，说明插件能正确读到正文，生图就能拿到上下文了。
