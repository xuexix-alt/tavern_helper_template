==========
同层版界面接 st-chatu8 生图链说明
==========

当前 `src/寒冬末日/界面同层版` 对接生图插件时，不应自己重做一套生图系统，而应继续复用酒馆环境里已经存在的 `st-chatu8` 原逻辑。

硬约束如下：

1. UI 只做代理，不自己替代插件
- 正文区双击动作，要尽量路由回原 chat 楼层里的原生触发节点。
- 插件仍按它自己的原 chat 流程处理：拿正文、生成提示词、发起生图、把图片插回聊天记录或缓存。
- 同层版 UI 不直接在前端新造一套“提示词状态机”或“图片真相”。

2. 右侧图廊只是收集器
- 图廊只统一展示已经进入 chat 或插件缓存中的图片。
- 图廊不是图片的真源，也不是重生逻辑的执行者。
- 图廊内的图片点击、双击，要尽量再代理回原楼层对应图片或按钮节点，保留宿主原语义。

3. 需要保留的原交互
- 双击正文：触发该楼层原生生图入口。
- 单击已有图片：查看同一 `mes` 文本对应的其他图片。
- 双击已有图片：按原链路重新生成。

4. UI 刷新职责
- 提示词生成中：允许只更新当前楼层的局部图片状态，不做全量刷新。
- 图片成功回传后：重新从 chat 正文和插件缓存采集该楼层图片，再同步到正文卡片和右侧图廊。
- 如果这条生图链没有引起 `stat_data` 变化，则左侧变量区默认不刷新。

5. 可靠性优先级
- 优先保证“动作回到原楼层原节点”。
- 优先保证“图廊只是收集和转发，不篡改原逻辑”。
- 如果某张图在图廊中找得到、但无法可靠映射回原楼层节点，宁可只展示，不要擅自模拟出另一套不一致的交互。

建议在同层版里重点使用这些定位信息来回找宿主节点：
- `messageId`
- `requestId`
- `promptToken`
- `imageSrc`

推荐的处理顺序：
1. 先按 `requestId` 找原按钮或原图片节点
2. 找不到再按 `promptToken` 匹配
3. 还找不到再按 `imageSrc` 做兜底匹配
4. 只有在确认定位到宿主节点后，才转发点击或双击事件

这一段说明的目标只有一个：
同层版界面负责“桥接和展示”，`st-chatu8` 负责“实际生成和原生图片交互逻辑”。

        // 假设 eventOn, eventEmit, eventRemoveListener 是由宿主环境（如SillyTavern）提供的全局函数。
        // 如果在普通浏览器中直接打开此文件，这些函数会是 undefined，点击按钮将报错。

        const EventType = {
            GENERATE_IMAGE_REQUEST: 'generate-image-request',

        const imageContainerEl = document.getElementById('image-container');
        const generateBtn = document.getElementById('generate-btn');
        const promptInput = document.getElementById('prompt-input');

        // 用于生成唯一ID的辅助函数
        const generateUniqueId = () => {
            return 'req-' + Date.now() + '-' + Math.random().toString(36).substr(2, 9);
        };

        // 记录日志到状态区域
        const logStatus = (message) => {

        generateBtn.addEventListener('click', async () => {

            const btnLoader = document.getElementById('btn-loader');

            // 检查事件函数是否存在
            if (typeof eventEmit !== 'function' || typeof eventOn !== 'function' || typeof eventRemoveListener !== 'function') {
                statusEl.textContent = `错误：事件函数 (eventEmit, eventOn, eventRemoveListener) 未定义。\n请在正确的宿主环境中运行此页面。`;
                return;
            }

            statusEl.textContent = '...'; // 清空日志
            imageContainerEl.innerHTML = ''; // 清空图片

            const prompt = promptInput.value;
            const change = document.getElementById('change-input').value;
            const width = document.getElementById('width-input').value;

            if (!prompt) {
                logStatus('错误：提示词不能为空！');
                return;

            const requestId = generateUniqueId();
            const requestData = {
                id: requestId,
                prompt: prompt,
                change: change,
                width: width ? parseInt(width, 10) : null,
                height: height ? parseInt(height, 10) : null,
            };

            logStatus(`准备发送请求，ID: ${requestId}`);
            logStatus(`请求数据: ${JSON.stringify(requestData, null, 2)}`);

            // 2. 定义本次请求对应的响应处理器
            const imageResponseHandler = (responseData) => {
                if (!responseData || responseData.id !== requestId) {
                    return;

                // 恢复按钮状态

                btnText.style.display = 'inline';
                btnLoader.style.display = 'none';

                const { success, imageData, error } = responseData;

                if (success) {
                    logStatus('图像生成成功！');
                    const img = document.createElement('img');
                    img.src = imageData;
                    img.alt = `生成的图片: ${prompt}`;
                    imageContainerEl.appendChild(img);
                } else {
                    logStatus(`图像生成失败: ${error}`);
                }
            };

            // 1. 开启监听
            eventOn(EventType.GENERATE_IMAGE_RESPONSE, imageResponseHandler);
            logStatus(`已开启对 ID: ${requestId} 的响应监听。`);

            // 更新按钮为加载状态
            generateBtn.disabled = true;
            btnText.style.display = 'none';
            btnLoader.style.display = 'inline-block';

            // 3. 发送请求
            logStatus(`发送生成请求...`);
            await eventEmit(EventType.GENERATE_IMAGE_REQUEST, requestData);
            logStatus('请求已发送，等待后端响应...');
