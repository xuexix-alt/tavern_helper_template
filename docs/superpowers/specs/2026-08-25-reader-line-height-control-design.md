# 正文行距滑块设计

## 目标

在同层 PRE 的“阅读与排版设置”中增加独立的正文行距滑块，让用户即时调整 AI 正文的 `line-height`，并在当前聊天内保存选择。

## 交互

- 在现有“排版”弹窗的字体风格之后放置“正文行距”组件。
- 滑块范围为 `1.30` 到 `2.10`，步长为 `0.05`。
- 标签实时显示当前值；未自定义时显示“自动”，并跟随阅读密度：舒适 `1.90`，极简 `1.70`。
- 提供“恢复自动”按钮。恢复后不再写死行距，继续跟随舒适/极简模式。
- 拖动时即时影响当前显示，无需点击保存。

## 作用范围

- 自定义值只覆盖 AI 正式正文与开局正文。
- 不修改用户消息、角色卡、工具栏、弹窗说明和其他 UI 文本。
- 流式正文中的内容继续继承正文行距，因此生成中与生成完成后的排版一致。
- 段落下边距保持现状；本组件只调整字体行高。

## 状态与兼容

- 新状态字段为 `body_line_height: number | null`，保存在现有聊天变量 `stream_demo.reader_state` 中。
- `null` 表示自动；有限数字会被钳制到 `1.30–2.10` 并按 `0.05` 对齐。
- 阅读状态版本从 `4` 升为 `5`。旧聊天迁移后默认得到 `null`，视觉保持原有舒适/极简行距。
- 页面根节点仅在存在自定义值时设置 CSS 变量 `--reader-body-line-height`；正文组件通过带原默认值的 `var(...)` 使用它。

## 组件边界

- `ReaderLineHeightControl.vue`：负责滑块、数值标签和恢复自动事件，不直接读写酒馆变量。
- `readerLineHeight.ts`：集中维护范围、步长、密度默认值和数值规范化。
- `TopToolbar.vue`：承载新组件并透传 `v-model`。
- `useStreamingDemo.ts` 与 `readerState.ts`：负责响应式状态、恢复及聊天变量持久化。
- `StoryPage.vue`：把状态连接到排版面板，并发布正文 CSS 变量。

## 验证

- 单元测试覆盖数值钳制、步长对齐和不同密度的自动值。
- 源码契约测试覆盖组件接线、聊天状态迁移、CSS 变量以及普通/开局正文的覆盖范围。
- 运行现有正文布局回归测试，确保流式布局、正文宽度和旧默认主题不受影响。
