# 伊甸等级、能力与救亡世界书

用户已确认采用：救亡任务替换旧主线，伊甸本体等级独立于农业/工业/气象技术lv0—5；技术首次取得与自持生产体系首次建成分别结算，仅灾后承担30天成果义务。

## 使用

同步新版pre界面、伊甸后台数据辅助脚本及原角色世界书规则后，打开「系统 → 能力」。默认展示能力看板，未解锁能力收起；点击顶部「编辑」才进入草稿表单，可调整四级名称、当前等级、六组能力、启用条件与授权供能房号。原等级超过4级须另行确认迁移，正式保存前不改旧数据。

「救亡任务」与「技术」默认只读展示当前任务、已知线索和已确认成果，不展示或编辑完整世界书设定。玩家可点击「登记成果」确认剧情中实际取得的技术或建成的生产体系；已知技术使用分支及lv0—5构成稳定编号，自持生产体系使用玩家填写的稳定编号。登记不编辑能力或世界书规则。

每次修改后点击「预览世界书」，核对AI实际会读到的条目，再点击「确认写入」。继续编辑将使预览失效。取消恢复正式版本，保存失败保留草稿。重新打开从当前聊天绑定的世界书读取。编辑期间切换聊天或换绑世界书会阻止旧草稿误写；版本冲突须重新载入。

## 正式数据

当前聊天专属世界书中的 `[伊甸设定]等级与能力` 保存结构化文档和完整能力目录，本条目关闭AI注入。其余条目为蓝灯、系统深度1：`当前伊甸`、`当前救亡任务`、`当前伊甸技术`、`[伊甸设定]末日救亡任务`、`[伊甸设定]伊甸技术`。只更新带本功能owner标记的条目，保留手机、人物和开局条目；遇到同名非本功能条目时报错。

首次确认后，聊天变量 `eden.worldbookManaged` 标记新模式。后台从世界书载入文档，以缓存投影旧MVU显示字段，跳过旧掷点、升级奖励、范围写入与性能摘要。文档缺失或载入失败时不回退执行旧升级。旧世界书的任务、奖励及复杂共鸣指令通过EJS条件分流；未迁移存档继续旧机制。

能力所需等级、启用开关和特殊条件共同决定实际可用状态。默认高阶模块替代旧模块，避免重复注入冲突限制。对外供暖供电还须明确登记房号，不自动带来供水、制造、监控与安防。旧MVU字段是显示投影，不是正式能力定义的写入口。

## 灾后期限与剧情回退

灾前确认时从灾变日开始计时；灾后旧存档首次确认时从确认日开始，避免追溯处罚。恰好30天未完成仍未逾期，超过30天则停机。技术与生产成果分别重置期限。记录使用源楼层剧情前缀指纹，删除、重生或修改源剧情后旧成果不能随楼层编号复用而重新生效，根据新剧情重新登记时允许替换失效来源，仍有效的同一成果继续禁止重复结算。

一旦成果时间线上出现超过30天的空档，新成果不会自动解除停机。玩家可以在能力编辑态明确点击「人工确认恢复」，再预览、确认保存；该操作才重置当前周期。独立实体物资不因停机消失。

前端每次生成前同步正式条目的当前日期与权限，重生先删除旧回复再同步。后台变量结算后也刷新运行条目。失败会阻止pre继续发出携带过期状态的请求。

灾前不执行后台离场健康加减。跨越灾变的一轮只计算灾变后的时长；A档进入灾后恢复正常结算。剧情直接造成的伤病与治疗仍由原剧情更新处理。
