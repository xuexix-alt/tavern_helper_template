# 小手机聊天 APP 微信化设计

## 目标

统一重做 `src/小手机/脚本/聊天APP/index.ts` 的会话列表、聊天详情和新建会话弹窗，使界面简单但具备微信的核心视觉特征。保留现有 ChatDB、ChatCore、ChatSync、会话创建和异步保护逻辑。

## 会话列表

- 使用微信式浅灰顶栏，标题为“微信”，右侧提供刷新和新建按钮。
- 会话使用白底连续列表，不使用悬浮卡片。
- 每项包含方形圆角头像、名称、最后消息摘要、右侧时间和可选未读角标。
- 私聊头像显示姓名首字，群聊头像使用简洁的四宫格成员占位，不使用 emoji 图标。
- 空、加载和错误状态沿用现有状态机，但统一为微信式空白提示。

## 聊天详情

- 顶栏包含返回按钮、会话名和更多按钮。
- 消息区使用微信灰背景；对方消息为左侧头像加白色尖角气泡，玩家消息为右侧头像加绿色尖角气泡。
- 群聊对方消息显示发送者名称；系统消息显示为居中的半透明灰色提示条。
- 时间信息使用居中时间条，不挂在每个气泡底部。
- 生成中状态显示为对方气泡内的三点输入指示，不使用 emoji 文案。
- 输入栏使用白色底栏、圆角输入框和微信绿色发送按钮，触控目标不小于 44px。

## 新建会话弹窗

- 使用底部弹出的白色圆角面板和半透明遮罩。
- 第一层显示“发起私聊”“发起群聊”；第二层显示联系人选择、群名输入、错误提示以及取消/确定操作。
- 选中状态使用微信绿色勾选圆点；加载、空和重试状态继续使用现有数据逻辑。

## 实现边界

- 仅修改渲染结构、内联样式及必要的纯展示辅助函数。
- 不改变数据库结构、消息生成、正文同步、角色候选读取和并发取消行为。
- 不加载外部图片、字体或图标库；图标使用内联 SVG/CSS。
- 支持 375px 及以上移动宽度，无水平滚动，并保留键盘焦点样式。
