# 微信 APP 入口图标实施计划

## 目标

把用户提供的 PNG 原字节内联到小手机脚本中，仅替换首页进入微信聊天列表的入口图标，保持路由、聊天头像和其他 APP 图标不变。

## 实施步骤

1. 在 `src/小手机平台/assets/wechatIcon.ts` 中保存 PNG data URL，并用测试校验解码后的 SHA-256。
2. 为 `PhoneAppDefinition` 增加可选 `iconSrc`，只在 `messages`（微信）定义中设置该字段。
3. 为首页图标提取可测试的 DOM 创建函数：有 `iconSrc` 时渲染装饰性 `<img>`，否则保留 glyph。
4. 增加图片填充、圆角继承和无旧蓝底覆盖的 CSS。
5. 运行小手机外壳测试、格式检查和完整构建；检查构建产物只保留本任务及已有 ChatLore 改动。
6. 用移动端视口检查首页微信图标的实际 DOM 和截图；若无可连接的酒馆运行时，明确标注验证边界。

## 验收

- 首页“微信”显示指定绿色 PNG，点击仍进入 `messages`。
- 图片字节哈希为 `231218A7264273DC445FB158DD92BC5D34BEE32EF017827F666027E9CB01AD21`。
- 其他 APP 继续显示原 glyph，聊天列表及消息头像不受影响。
- `pnpm build` 成功。
