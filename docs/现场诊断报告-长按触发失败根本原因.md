## 🎯 问题链路分析

### 正常流程应该是：

```
1. LLM返回文本，包含 image###prompt### 标记
   ↓
2. 插件（st-chatu8）解析标记
   ↓
3. 插件发送 generate-image-request
   ↓
4. 图片生成完成，插件收到 response
   ↓
5. 插件写入 chat[mesId].extra.images
   ↓
6. 插件在宿主DOM中插入 <img> 和 <button>
   ↓
7. 同层UI扫描宿主DOM，读取图片
   ↓
8. 用户长按图片 → Same-layer UI触发
   ↓
9. Same-layer UI查找宿主DOM中的按钮/图片
   ↓
10. 触发插件的右键菜单 ✅
```

### 当前实际情况：

```
1-4. ✅ 正常（图片已生成）
5. ⚠️ 不确定（需要检查 chat[13].extra.images）
6. ❌ **断层点**：宿主DOM中没有图片元素
7. ✅ 同层UI通过其他方式读取到了图片（可能直接读取extra.images）
8-9. ❌ 长按时找不到宿主DOM目标
10. ❌ 无法触发插件菜单
```

## 💡 可能的原因

### 原因1：插件没有渲染图片到宿主DOM

**可能性**：⭐⭐⭐⭐⭐（最可能）

插件可能：
- 图片数据存储在 `extra.images` 中
- 但没有调用DOM插入逻辑
- 或者DOM插入被某个条件阻止

**验证方法**：
```javascript
// 检查 chat[13].extra.images 是否有数据
const msg13 = getMessageById(13);
console.log(msg13.extra?.images);
```

### 原因2：插件DOM被清理或隐藏

**可能性**：⭐⭐⭐

可能的触发条件：
- 同层UI加载时清理了宿主DOM
- 酒馆的某个刷新操作移除了插件DOM
- CSS样式隐藏了图片元素

**验证方法**：
```javascript
// 检查是否有隐藏的图片
const hidden = msg13.querySelectorAll('.st-chatu8-image-container[style*="display: none"]');
```

### 原因3：图片是旧消息，插件版本不兼容

**可能性**：⭐⭐

这个聊天是 "2026-05-27 imported"，可能：
- 图片数据格式是旧版本
- 当前插件版本无法渲染旧格式
- 需要重新生成图片

## 📋 修复建议

### 短期方案（立即可用）

**方案A：强制重新渲染插件图片**

在同层UI挂载时，主动触发插件重新处理图片：

```typescript
// useStreamingDemo.ts - onMounted
onMounted(() => {
  // ... 现有逻辑
  
  // 强制触发插件图片渲染
  window.setTimeout(() => {
    const visibleMessages = document.querySelectorAll('.mes[mesid]');
    
    visibleMessages.forEach(msg => {
      const mesText = msg.querySelector('.mes_text');
      if (!mesText) return;
      
      // 检查是否有image###标记但没有实际图片
      const hasMarker = mesText.innerHTML?.includes('image###');
      const hasContainer = msg.querySelectorAll('.st-chatu8-image-container').length > 0;
      
      if (hasMarker && !hasContainer) {
        console.log(`[fix] 消息 ${msg.getAttribute('mesid')} 需要重新渲染图片`);
        
        // 触发插件重新处理
        if (typeof window.processChatu8Images === 'function') {
          window.processChatu8Images(msg);
        }
        
        // 或者触发DOM变化事件
        const event = new Event('DOMSubtreeModified', { bubbles: true });
        mesText.dispatchEvent(event);
      }
    });
  }, 1500);
});
```

**方案B：增强降级方案，直接构造点击事件**

如果找不到目标，不只是降级到 `mes_text`，而是直接构造一个包含图片信息的点击事件：

```typescript
// StoryPage.vue - activateGeneratedImageTag
if (!targetNode) {
  console.warn('[image-tag] 未找到精确目标，尝试直接触发插件');
  
  // 构造包含图片信息的自定义事件
  const customEvent = new CustomEvent('st-chatu8-image-action', {
    bubbles: true,
    detail: {
      action: 'tag',
      messageId: Math.trunc(messageId),
      promptToken: promptToken,
      imageSrc: imageSrc
    }
  });
  
  const mesTextRoot = resolveHostMessageTriggerTarget(Math.trunc(messageId));
  if (mesTextRoot) {
    mesTextRoot.dispatchEvent(customEvent);
    return;
  }
  
  toastr?.warning?.(`楼层 #${Math.trunc(messageId)} 的图片 tag 修改目标未找到`);
  return;
}
```

### 长期方案（需要插件配合）

// st-chatu8插件中
