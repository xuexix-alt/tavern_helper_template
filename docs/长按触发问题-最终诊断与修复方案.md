> **诊断时间**: 2026-06-04  
> **状态**: ✅ 根本原因已确认  
> **结论**: 插件未渲染图片到宿主DOM，需要额外修复

## 📊 问题确认

### 现场验证结果

```javascript
// 消息13的图片状态

宿主DOM: ❌ 0个图片容器、0个图片按钮、0个图片元素
画廊显示: ✅ 8张图片正常显示
插件状态: ✅ 已加载（日志确认）
图片渲染: ❌ 插件未渲染图片到宿主DOM（等待2秒后仍为0）

// 画廊图片数据
messageId: "13"         ✅
markerId: "gm:13:1b97inr" ✅
requestId: ""           ❌ 空
promptToken: ""         ❌ 空
```

### 根本原因

**插件的图片标记存在于正文中，但插件没有渲染实际的DOM元素**

可能原因：
1. 这是一个 imported 的旧聊天（2026-05-27），插件可能不会重新渲染旧消息的图片
2. 插件需要某个触发条件才会渲染（如重新生成、刷新消息等）
3. 插件版本兼容性问题

## 🔧 补充修复方案

### 方案1：强制触发插件重新渲染（推荐）

**原理**: 监听到图片标记但没有DOM元素时，触发一个DOM事件强制插件重新处理

**实施位置**: `useStreamingDemo.ts - onMounted`

```typescript
// useStreamingDemo.ts:7100
onMounted(async () => {
  // ... 现有逻辑
  
  // 新增：检查并修复缺失的图片DOM
  window.setTimeout(() => {
    const visibleMessages = document.querySelectorAll('.mes[mesid]');
    
    visibleMessages.forEach(msg => {
      const mesText = msg.querySelector('.mes_text');
      if (!mesText) return;
      
      // 检查是否有image###标记但没有实际图片容器
      const rawHTML = mesText.innerHTML || '';
      const hasImageMarker = rawHTML.includes('image###');
      const imageContainers = msg.querySelectorAll('.st-chatu8-image-container');
      
      if (hasImageMarker && imageContainers.length === 0) {
        const mesId = msg.getAttribute('mesid');
        console.log(`[image-dom-fix] 消息 ${mesId} 有图片标记但无DOM，触发重新渲染`);
        
        // 方法1：触发DOM变化事件（最温和）
        const mutationEvent = new Event('DOMSubtreeModified', { 
          bubbles: true,
          cancelable: false 
        });
        mesText.dispatchEvent(mutationEvent);
        
        // 方法2：触发自定义事件（如果插件支持）
        window.setTimeout(() => {
          const customEvent = new CustomEvent('st-chatu8-reprocess-images', {
            bubbles: true,
            detail: { messageId: mesId }
          });
          msg.dispatchEvent(customEvent);
        }, 100);
        
        recordLifecycleTrace('imageDomFix', 'trigger_rerender', {
          messageId: mesId,
          markerCount: (rawHTML.match(/image###/g) || []).length
        });
      }
    });
  }, 2000); // 等待插件初始化完成
});
```

**优点**：
- ✅ 主动修复缺失的DOM
- ✅ 不依赖用户手动操作
- ✅ 兼容插件的现有逻辑

**缺点**：
- ⚠️ 需要插件响应DOM事件（大概率会响应）
- ⚠️ 增加了挂载时的处理时间

```typescript
      // 如果有promptToken或imageSrc，尝试匹配
      let matchedMarker = null;
      
      if (promptToken) {
        matchedMarker = imageMarkers.find(marker => 
          marker.includes(promptToken.replace(/###/g, ''))
        );
      } else if (imageSrc) {
        // 通过imageSrc的特征匹配（如果有的话）
        matchedMarker = imageMarkers[0]; // 默认使用第一个
      } else {
        matchedMarker = imageMarkers[0];
      }
      
      if (matchedMarker) {
        const extractedPrompt = matchedMarker.match(/image###([^#]+)###/)?.[1];
        console.log(`[image-tag] 匹配到标记，提取prompt: ${extractedPrompt?.substring(0, 50)}...`);
        
        // 构造自定义事件，传递给插件
        const customEvent = new CustomEvent('st-chatu8-manual-tag', {
          bubbles: true,
          detail: {
            messageId: Math.trunc(messageId),
            prompt: extractedPrompt,
            action: 'tag'

        toastr?.info?.('正在打开图片标签编辑器...');
        
        return; // 不要fallback到warning
      }
    }
  }
  
  // 如果还是失败，才显示warning
  toastr?.warning?.(`楼层 #${Math.trunc(messageId)} 的图片 tag 修改目标未找到`);
  return;
}
```

**优点**：

- ✅ 充分利用现有的promptToken数据
- ✅ 用户体验更好（有提示）

**缺点**：
- ⚠️ 需要插件监听自定义事件（可能需要插件更新）
- ⚠️ 代码复杂度增加

### 方案3：提示用户重新生成（最简单）

**原理**: 检测到缺失DOM时，显示友好提示引导用户

**实施位置**: `pages/StoryPage.vue - activateGeneratedImageTag`

```typescript
// StoryPage.vue:1950（降级逻辑处）
if (!targetNode) {
  const mesTextRoot = resolveHostMessageTriggerTarget(Math.trunc(messageId));
  
  if (!mesTextRoot) {
    toastr?.warning?.(`楼层 #${Math.trunc(messageId)} 的图片 tag 修改目标未找到`);
    return;
  }
  
  // 新增：检查是否有image###标记
  const mesTextHTML = mesTextRoot.innerHTML || '';
  const hasImageMarker = mesTextHTML.includes('image###');
  const hasImageDOM = document.querySelector(`.mes[mesid="${messageId}"] .st-chatu8-image-container`);
  
  if (hasImageMarker && !hasImageDOM) {
    // 这是一个有标记但没有DOM的情况
    toastr?.warning?.(
      `此楼层的图片尚未加载到页面。请尝试：\n1. 刷新页面\n2. 重新生成此楼层`,
      '图片未加载',
      { timeOut: 8000 }
    );
    return;
  }
  
  targetNode = mesTextRoot;
}
```

**优点**：
- ✅ 实施最简单
- ✅ 告知用户问题和解决方法
- ✅ 不增加复杂度

**缺点**：
- ❌ 需要用户手动操作
- ❌ 体验不如自动修复
