## 🎯 档案系统工作流程

### 数据收集流程

```
1. 从 MVU 变量读取基础人物信息
   ├─ 租客列表.人名.年龄
   ├─ 租客列表.人名.职业
   ├─ 租客列表.人名.外貌
   ├─ 租客列表.人名.性格
   └─ 租客列表.人名.关系

2. 从聊天记录提取互动信息
   ├─ 聊天总条数
   ├─ 最后一条消息内容
   └─ 最后互动时间

3. 从广播中查找相关提及
   └─ 匹配人名的广播内容（最多3条）

4. 生成档案
   ├─ 基本信息: 年龄 + 职业 + 外貌
   ├─ 性格: 从 MVU 读取
   ├─ 当前状态: 从 MVU 读取
   ├─ 关系: 从 MVU 读取
   └─ 最近互动: 聊天摘要 + 广播提及
```

### 类型定义

```typescript
export interface PhoneProfileView {
  id: string;                 // 人物 ID
  name: string;               // 姓名
  basicInfo: string;          // 基本信息
  personality: string;        // 性格
  currentStatus: string;      // 当前状态
  relationship: string;       // 关系
  recentInteraction: string;  // 最近互动
  lastUpdated: number;        // 更新时间戳
}
```

### 核心函数

#### `collectProfiles(db, sessionKey)`
从多个数据源收集人物档案信息。

#### `refreshSingleProfile(db, sessionKey, personId)`
刷新单个人物的档案信息。

#### `getContactsFromMvu()`
从 MVU 变量读取联系人基础信息。

#### `collectChatSummaries(db, sessionKey)`
从聊天记录提取摘要信息。

#### `collectBroadcastMentions(db, sessionKey)`
从广播中提取人物相关信息。

## 🚀 使用指南

### 在小手机中查看档案

1. 打开小手机（点击"伊甸终端"）
2. 点击"档案" APP
3. 查看所有人物档案
4. 点击 🔄 按钮刷新档案

### 刷新档案触发条件

- **手动刷新**: 点击 🔄 按钮
- **自动更新**: 每次打开档案 APP 时重新收集数据

### 数据更新策略

- 档案数据实时从数据库和 MVU 变量读取
- 不进行缓存，每次打开都是最新数据
- 轻量级实现，性能开销小

## 🐛 已知限制

1. **MVU 依赖**: 需要 `租客列表` 变量存在
2. **人名匹配**: 广播提及使用简单字符串匹配，可能误匹配
3. **数据量**: 如果聊天记录过多，可能影响性能
4. **无缓存**: 每次打开都重新计算，无持久化
