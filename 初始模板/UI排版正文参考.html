    API Error: no candidates returned

    这表示AI收到的指令过长，超出了其单次处理的极限。这通常发生在游戏后期，因为我们详尽的状态系统会累积大量信息。这个问题在v36.0版本中已通过多种优化手段极大缓解。如果偶尔仍出现此问题，请尝试【存档】后立刻【读档】，这相当于为AI清理缓存，让故事能顺利继续。

    (AI未提供对话)

    这曾是AI模型未能按预期格式生成回复时的备用信息。在新版[v23.0]中，此问题已基本被解决。系统现在能智能解析不完整的AI回复，只要AI生成了任何文本，都会被展现为剧情。如果此消息依然出现，代表AI返回了完全空洞的内容。

    AI没有返回任何内容，可能需要重试

    这表示与AI模型的通信已建立，但模型返回了空内容。这可能是暂时的网络问题、API服务不稳定或模型内部错误。请尝试重新发送您的消息或稍后再试。

    读取失败: 这是一个空档位

    您尝试读取的存档位中没有数据。请选择一个有数据的存档位进行读取。

    读取失败: 存档数据已损坏

    存档文件存在，但其内容格式不正确，无法被系统解析。这可能是因为存档在保存过程中被中断，或文件被意外修改。此存档已无法恢复。

    处理请求时发生未知错误

    在向AI发送请求或处理其返回数据的过程中，发生了代码无法预料的JavaScript错误。这通常是系统内部的BUG。您可以尝试刷新页面或读取之前的存档。
